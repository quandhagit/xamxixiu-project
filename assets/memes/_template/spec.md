# Meme asset spec

Copy this folder into a meme category, rename it, and add one video or image
file next to this document. Every asset needs its own specific use case.
Do not reuse a generic "short visual punchline" description.

## Asset

- Best for: Calling out a lie / xạo, not generic suspicion.
- Tone: suspicious / confrontational
- Intensity: 0.7
- Works with comments that: Accuse someone of making it up, gaslighting, or stacking excuses.
- Do not use when: The comment is sincere agreement, real grief, or already a laugh-out-loud punchline.
- Suggested SFX: none
- Suggested animation: none

For video memes, use `none` for both Suggested SFX and Suggested animation.

## Selection guidance

Write the exact editing moment. Mention sibling assets to avoid
("softer than Cheems bonk", "not the transition quack"). Focus on
context and comedic effect rather than only the emotion label.
